# Data dictionary (provisional)
Source: NISR microdata catalogue, SAS 2024 (files F6, F3, F10; ~35,584 / 39,330 / 1,949 cases). Variable names and labels are in `ml/preprocessing/columns.json`.
App record format (`data/processed/records.json`): district, province, crop, season, plot_area_sqm, improved_seed, fertilizer_inorganic, irrigated, erosion, mechanized, production_kg, yield_kg_ha.
